# Klever Flow\n\nKlever Flow is a Klever Group water-account management project. This repository currently deploys the public project introduction page. The PHP/MySQL management MVP is not yet connected to this public release. Live payment processing and physical valve/IoT control are not enabled. Do not accept payments through this site.\n\nRuntime: PHP 8.2 with Apache and PDO MySQL extension. Railway deploys using the included Dockerfile.\n
